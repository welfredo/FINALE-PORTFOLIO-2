# Welfredo Sumcad — BSIT Portfolio

## Files
- `index.html` — portfolio page
- `style.css` — styles, violet Mock Interview section, responsive layout, and woven lanyard effects
- `script.js` — interactions and animations
- `image.png` — profile photo used by the ID card and resume
- `student-portal-showcase.png` — project showcase image
- `mock-interview.mp4` — embedded mock interview video
- `certificates/` — certificate images
- `demos/` — salon and sales-analysis demo projects

## Publish on GitHub Pages
1. Extract the ZIP.
2. Upload the files and folders inside this folder to the root of your GitHub repository.
3. Commit the changes.
4. In the repository, open **Settings → Pages** and publish from the `main` branch and `/ (root)` if Pages is not already enabled.
5. Open the published website and scroll to **Mock Interview** to play the MP4.

Keep `mock-interview.mp4` in the same root folder as `index.html`, because the video player references it by that filename.

The video is about 20 MB, which is under GitHub's 25 MiB per-file browser upload limit. Uploading the complete project ZIP itself is not necessary; upload the extracted files/folders.
